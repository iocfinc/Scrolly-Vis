## Overview

This directory is a reusable Codex project boilerplate. Treat it as a starter kit for new repositories that should work well with Codex, Codex CLI, and similar coding agents.

## Working Rules

- Start by reading [`codex-best-practices.md`](./codex-best-practices.md) and the relevant files under [`project-template/`](./project-template).
- Prefer adapting the templates instead of writing new process files from scratch.
- Keep instructions short, operational, and testable.
- Put repository-wide instructions in the root `AGENTS.md`.
- Add nested `AGENTS.md` files only when a subdirectory genuinely needs different commands, rules, or architecture notes.
- Keep skills concise and move deep details into `references/` files.

## Boilerplate Layout

- [`project-template/`](./project-template): reusable files for new Codex-friendly repos.
- [`skills/`](./skills): starter skills for common project setup and repo operations.
- [`codex-best-practices.md`](./codex-best-practices.md): distilled research and practical guidance.
