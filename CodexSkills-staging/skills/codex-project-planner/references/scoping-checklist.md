# Scoping Checklist

## Core Questions

- What exact user problem does this project solve?
- What is the smallest version that proves value?
- What must exist on day one versus later?
- What environments must be supported?
- What commands should pass before a task is considered complete?

## Repo Design Checks

- Is the root layout obvious to a new engineer?
- Are validation commands documented in one place?
- Are generated files clearly marked?
- Does the project need nested `AGENTS.md` files or just one root file?

## Prompting Checks

- Does the task specify in-scope and out-of-scope work?
- Does it include acceptance criteria?
- Does it name files or directories that must not change?
